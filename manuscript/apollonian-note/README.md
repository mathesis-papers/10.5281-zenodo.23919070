# MathOverflow 516405: the extreme adjacency eigenvalues

The note proves that the second ordinary adjacency eigenvalue of the inner-face Apollonian stages, divided by `2^(m/2)`, tends to `sqrt(2)`. It also determines every fixed-rank eigenvalue at both ends of the spectrum and gives an explicit finite-stage error bound and an `O_r(2^(-m/4))` rate.

## Files

- `note.tex`: self-contained mathematical source and bibliography.
- `note.pdf`: typeset note.
- `metadata.json`: creators, license, problem identifier and pinned mathematical source.
- `verify.py`: exact finite graph and Gram-identity checks, followed by floating-point extreme eigenvalue calculations.
- `checks.json`: reproducible results for stages 0 through 8, with 26 cutoff-stage pairs and eigenpair residuals; delivered separately from the source archive and regenerated by the command below.

## Build

Build with **Tectonic 0.17.0**:

```sh
tectonic --untrusted note.tex
```

Alternatively, use `pdflatex note.tex` twice. The bibliography is included directly in the source; BibTeX is not required. No additional source files or figures are needed.

## Finite checks

Use Python 3 with NumPy and SciPy:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 verify.py --max-stage 8 --output checks.json
```

The script bounds its graph range to stages 1 through 9. Its default calculation includes the initial stage 0 and ends at stage 8, with 9,844 vertices. Integer checks cover graph and face counts, all vertex degrees, incidence, the exact cutoff Gram formula and birth-oriented degree bounds. Floating-point checks calculate up to eight eigenvalues at each end of the adjacency spectrum and record their absolute eigenpair residuals. They illustrate the formulas rather than establish the infinite limits.

## Mathematical coverage

The written proof establishes the exact Gram identity, both fixed-rank spectral limits, the quantitative estimate, the convergence rate and the square-root-of-degree corollary.

At upstream commit `66d225eda69544653f1ca0e66cf3aea530b1a2c6`, the declaration `D5.S3.Combinatorics.Apollonian.SecondEigenvalueLimit.result` formalizes the original second-eigenvalue limit for all natural stages with multiplicity. The note links this declaration and each relevant companion `.lean` file, stating its scope. The additional fixed-rank and quantitative results have the written proofs in the note.

The posing source is Rad Sarar Anando's MathOverflow question 516405, revision 1, dated October 26, 2026. The note distinguishes the deterministic graph from random Apollonian networks and degree-normalized hopping models. It makes no literature-priority claim.
